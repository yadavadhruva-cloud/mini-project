# The Olive Table — Catering Website

A six-page responsive catering website built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — Our Story
- `menu.html` — Menu with category filters
- `services.html` — Catering services
- `gallery.html` — Gallery
- `contact.html` — Contact and enquiry form

## Run it
Open `index.html` in a browser, or open this folder in VS Code and use the Live Server extension.

## Before submitting or publishing
1. Replace **The Olive Table** with the actual business name if needed.
2. Update the sample email, phone number, location and office hours in the footer and contact page.
3. Replace the sample menu items, photos and descriptions with the business's real offerings.
4. The contact form currently validates in the browser and displays a confirmation message. It does not send email until connected to a backend or form service.
5. Photos are loaded from Unsplash, and Google Fonts are imported online, so an internet connection is needed for those assets.

## Structure
- `css/style.css` — all styling and responsive layout
- `js/main.js` — mobile navigation, menu filters and enquiry form behaviour
